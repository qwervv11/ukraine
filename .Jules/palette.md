## 2024-05-12 - Added ARIA labels to icon-only buttons and global focus styles
**Learning:** Found several icon-only buttons missing ARIA labels (e.g. map modal close, lightbox close, scroll to top) and the site completely lacked keyboard focus styles (`:focus-visible`), hindering accessibility.
**Action:** Always ensure custom modal close buttons and global interactive elements have descriptive ARIA labels, and implement a global `:focus-visible` to aid keyboard navigation.
## 2024-05-19 - Added keyboard accessibility to custom interactive gallery items and dynamic lightbox close functionality via Escape
**Learning:** The gallery items `.gallery-item` were implemented as `div` elements acting like buttons (with a click listener for the lightbox) but were entirely inaccessible via keyboard. They lacked `tabindex`, `role="button"`, ARIA labels describing the image they would open, and `keydown` event listeners for 'Enter' or 'Space'. Additionally, the dynamically created lightbox only had a global Escape listener that worked for the static `#lightboxOverlay`, but not for the dynamically appended one.
**Action:** Always ensure that any non-semantic element (like `div`) used as an interactive component (e.g. to open a modal or lightbox) receives `tabindex="0"`, `role="button"`, a descriptive `aria-label`, and a `keydown` listener mapping 'Enter' and 'Space' to trigger the existing `click()` functionality. Additionally, when a dynamic modal/lightbox is appended to the DOM, explicitly attach and manage (add/remove) a dedicated 'Escape' key listener to ensure keyboard users can dismiss it.
